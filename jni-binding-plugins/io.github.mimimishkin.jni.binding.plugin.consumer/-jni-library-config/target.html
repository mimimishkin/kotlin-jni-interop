fun target(name: String, os: String, arch: String, abi: String, konanTarget: KonanTarget?, configure: Action<JniBindingTarget>): JniBindingTarget

Parameters

name of the target, e.g. "mingwX64".

os

arch

processor architecture name, see JniBindingTarget.arch.

abi

configure

additional configuration of the created target.
