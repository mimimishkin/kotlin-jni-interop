JniLibraryConfig

class JniLibraryConfig : HasProject, Named

Configuration of a single JNI library used by a JVM/Android compilation.

Configures per-platform binding sources (see targets), extra actuals policy, and where the binaries of the individual targets are packaged (see JniBindingTarget.copyToResources and JniBindingTarget.copyToJniLibs).
