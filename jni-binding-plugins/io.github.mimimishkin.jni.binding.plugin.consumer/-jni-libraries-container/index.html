JniLibrariesContainer

class JniLibrariesContainer(val compilation: KotlinCompilation<*>, backingContainer: NamedDomainObjectContainer<JniLibraryConfig> = jniLibraryConfigSet(compilation)) : NamedDomainObjectContainer<JniLibraryConfig> , HasProject

Container of JNI libraries configured for a single JVM/Android compilation.

Each element is a JniLibraryConfig named after its native library.
