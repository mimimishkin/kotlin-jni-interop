JniBindingTarget

interface JniBindingTarget : Named, HasProject

A single platform target of a JNI library binding.

Describes where the compiled native binary for this platform comes from (see fromProducer and fromPrebuiltBinding) and where it must be packaged (see copyToResources and copyToJniLibs).
