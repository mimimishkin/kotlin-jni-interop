popLocalFrame

context(env: JniEnv)
fun <T : JRef<O>, O : _jobject> popLocalFrame(result: T? = null): T?(source)

Pops off the current local reference frame, frees all the local references and returns a local reference in the previous local reference frame for the given result object.

Pass null as result if you do not need to return a reference to the previous frame.

Return

a local reference in the previous local reference frame for the given result object, or null if the given result object was null.

Since

JDK/JRE 1.2

Parameters

result

an object to be passed to the previous local reference frame, may be null.
